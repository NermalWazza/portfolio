What this work shows

Four capabilities, each demonstrated by the pieces below rather than asserted.

Design

Scoped briefs, authority boundaries and rollback for AI-assisted work — including where a task should stop for a human decision.

Build

Small, offline, standalone applications and documents that run without servers, trackers or external dependencies.

Direct

Delegating drafting and implementation to AI agents while keeping the decisions, approvals and publication call with a person.

Verify

Evidence labels, documented test results from earlier runs, file hashes and written limits — separating what was observed from what was only reported.

The common thread

These pieces ask one question from different angles: what changes when capable automation joins real work, and how do people stay accountable for the result? The acceleration report separates evidence from speculation. The Twin Engine shows one delegated brief becoming two tested applications — an UpFarm upgrade and the Cyber Red/Blue game, where defenders act on incomplete evidence — with the limits of the record written down. The Sorcerer’s Agent satirises what happens when scope and authority are missing. The Creative Software Convergence applies the same discipline to creative tools: it separates survey evidence, standards and proposals, and credits every image it shows. Across all five: label what is known, keep a human decision at the authority boundary, and record how it was checked.
