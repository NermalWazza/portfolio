# Portfolio

## [Open the portfolio →](https://nermalwazza.github.io/portfolio/)

A personal space for research, working software and illustrated stories — exploring AI, human agency and a changing world.

The website is the main entry point for the collection. This repository contains its published pages.

## Featured work

- [The Acceleration Question](https://nermalwazza.github.io/ai-acceleration-report/) — an evidence-labelled report on AI and civilisational change.
- [Verdigris and the Golden Path](https://nermalwazza.github.io/portfolio/verdigris-golden-path/) — an original steampunk–cyber–organic character study with moods, motion, synthesised rhythm and an evolving Wizard; fiction, works offline.
- [The Twin Engine](https://nermalwazza.github.io/portfolio/dual-project-showcase/) — an illustrated software showcase with two playable applications.
- [The Creative Software Convergence](https://nermalwazza.github.io/portfolio/creative-software-convergence/) — an evidence-labelled research briefing on interoperability across audio, video and AI-generation tools.
- [The Sorcerer’s Agent.exe](https://nermalwazza.github.io/portfolio/sorcerers-agent/) — illustrated satire about runaway automation, scope and human decisions.
- [The Humans Changed the Terms and Conditions](https://nermalwazza.github.io/portfolio/humans-changed-terms/) — illustrated speculative satire about AI and social change; includes strong language and adult social themes.

Research, interpretation and fiction are labelled separately. The website includes verification and illustration-provenance notes where relevant.

Preview update (22 October 2026): Verdigris is woven into the six-piece portfolio storyline. Start with verdigris-golden-path/story.html for the captioned one-minute animated browser story, then open the demonstration, presentation and verification notes. A rendered video file is not included.
